03 Охранное поле и размеры

3.1 Охранное поле

Вокруг логотипа всегда должно оставаться свободное пространство, равное высоте буквы «О» в названии (обозначим её X).

5.2 Правила набора

✓ Правильно

  • Название «ОСВОД» — всегда заглавными
  • Слоган — заглавными
  • Letter-spacing +6 … +8 для названия
  • Letter-spacing +2.5 … +3 для слогана

✗ Неправильно

  • Comic Sans, Papyrus, Times New Roman
  • Растягивать текст
  • Смешивать более 2 шрифтов
  • Курсив в логотипе

06 Правила использования

✓ Можно

  • Вертикальная версия для квадратных форматов
  • Горизонтальная — для широких носителей
  • Масштабировать пропорционально
  • Оставлять охранное поле
  • Монохром на сложных фонах

✗ Нельзя

  • Менять цвета логотипа
  • Растягивать / сжимать по осям
  • Вращать логотип
  • Добавлять тень, обводку, свечение
  • Размещать на пёстром фоне
  • Менять шрифт названия
  • Переставлять элементы знака
  • Рисовать логотип «по памяти»
